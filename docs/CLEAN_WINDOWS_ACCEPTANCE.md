# 干净 Windows 验收包

当前状态：已准备验收工具；尚未在干净 Windows 上完成验收。开发机自检不计为干净系统通过。

## 环境

使用新建 Windows 10 1809+ / Windows 11 x64 虚拟机或干净电脑，普通用户运行。不要预装 Python、Git、Node、Tesseract、ChatGPT 或应用本身。记录操作系统版本、来源/快照和显示缩放。Windows 10 与 Windows 11 应分别验收。

源码脚本支持系统自带 Windows PowerShell 5.1，无须安装 PowerShell 7。将验收 ZIP 解压到可写目录；不要在压缩包内部直接运行。

## 操作

1. 对照验收包外提供的 SHA-256 核对下载的 ZIP。
2. 打开普通 PowerShell，进入解压目录，先运行：

   ```powershell
   .\clean_windows_acceptance.ps1 -Phase Preflight
   ```

   查看 `results/preflight.json`。如果检测到开发工具、已有用户资料或已有安装，会拒绝安装；不要删除自己的资料来绕过检查，换干净测试账号/环境。PATH/注册表检查只是辅助，需要人工确认环境确实干净。
3. 运行 `.\clean_windows_acceptance.ps1 -Phase Install`。脚本核验安装包哈希，安装到独立中文路径，执行首次启动自检，再打开应用供人工验收。安装包未签名；遇到安全拦截交由环境负责人处理，脚本不会修改安全设置。
4. 逐项填写 `MANUAL-CHECKLIST.md`，只使用虚构学科和记录。不要输入真实 API 密钥或个人资料。离线情形请使用已隔离网络的测试环境；脚本不会修改网络或防火墙。
5. 退出应用后运行 `.\clean_windows_acceptance.ps1 -Phase Finish`，验证卸载保留数据库、重装不覆盖数据库、重装后自检正常。
6. 整理 `results` 和人工检查表。脚本不会自动上传结果，不会把未操作项目标记通过。应用和测试数据保留供复查；验收完毕可通过系统正常卸载，或还原虚拟机快照。

如果 PowerShell 执行策略不允许运行，先由测试人员检查脚本并按所在环境政策处理；不提供自动绕过执行策略的启动器。
