# 2026-10-09 页面切换与菜单动画修缮

## 修改

- 纸面底色、细微毛边和卷角改用 Qt Quick Shapes，保留纸纹、颜色、阴影和排版。尺寸变化时更新图形几何，减少整张 Canvas 的 CPU 绘制和纹理上传；也不再依赖 Canvas 首显重绘才能出现底色。
- 五个保留的主页面和计划子标签使用 `RetainedLoader`。隐藏页面保持离开时的尺寸并禁用交互，返回时更新至当前内容区尺寸，避免菜单动画和窗口缩放带着隐藏页面反复排版。
- 计划、记录、OJ、练习 PDF 标签首次访问后保留控件、滚动位置和草稿。切换标签清除预览令牌及复核勾选，关闭离开页面的阶段、归档及附件对话框，继续通过原服务复核和提交。
- 菜单标题和标签淡出时保留导航区域的垂直占位，收起、展开和快速反向切换不再让导航行突然跳动。宽度和文字淡出统一使用 NumberAnimation，避免当前 Qt 运行时混用 Animator 后出现的长间隔。
- 首页快速记录会明确重新填入请求的便笺；记录表单保留后，即使便笺与上次相同，也能覆盖用户在记录页改写的草稿，并清除旧预览。
- 图谱缩放复用关系线纹理，不重复绘制坐标未改变的线；关系线按可见节点索引查找端点，取消隐藏图谱的自动适配定时器。
- 把 Shapes 加入启动依赖探针，资源白名单和打包检查包含新增 Loader。

保留子标签会增加部分控件内存占用。未改变学习算法、数据库结构、线程池、外部服务授权及写入确认流程。

## 后续：首次进入的布局波动

用户反馈回访很快，但第一次进入仍有波动。原生采样复现计划标签先位于 y=20，随后位于 y=101；卡片在异步创建中曾以 280 像素宽、0/16/44 像素高出现，再扩展到最终尺寸。任务卡先落在 y=392，最后回到 y=260。第一次读取和控件创建的中间布局被提前呈现，观感类似重新加载。

`RetainedLoader` 现在将首次呈现与控件创建分开：保持控件参与布局，初始透明且禁用输入；等待初始数据或明确错误，以及两个布局后的窗口帧，再显示控件。帧回调在呈现后停止。五个主页面使用相同策略，计划子标签也等待布局帧；已呈现的实例不会因刷新或回访再次隐藏。首页不再先显示整页占位再替换成概览，图谱会在初始数据、选择与布局同步后一起出现。首次数据读取时间和控件创建成本仍然存在，加载期间使用固定位置的进度指示器。

计划页进入读取增加单次进入标记，防止完成和显隐信号重复请求。首页便笺跳转直接将内容送入已保留的计划页实例，首次尚未创建时才保留重试；避免在多层 Loader 绑定更新时依赖短定时器。
