# 主分支同步 1.0.0 发行版源码

同步日期：2026-10-21。

此前首页已经介绍 1.0.0，但发行版源码仍在 `codex/release-1.0.0` 和草稿 PR #8 中，`main` 的实际入口及界面仍是旧版 QWidget。此次将已发布的 1.0.0 QML 源码整合到主分支，版本元数据、启动入口、QML 页面、资源和打包清单一并同步。

## 版本关系

| 用途 | 源码基准 |
| --- | --- |
| 重现已发布的 1.0.0 安装包 | `v1.0.0`，提交 `60409ce2f7fa1c9097b8c715b3ae14763272808f` |
| 继续开发 QML 版本，并保留主分支维护修复 | 同步后的 `main` |

本次逐项核对 Release 的 `LearningModel-1.0.0-source.zip`：SHA-256 为 `5b3c7cef459ead2707d2897e0103f98b0bdc396d75e1aef48f3e0a5d1c42ef5e`，其中 648 个文件与 `v1.0.0` 的 Git blob 完全一致。此次合并保留全部发行版文件；`study_app/quick/` 下 71 个源码和资源文件与发行版逐字节一致。

## 保留的维护修复

主分支已有修复继续保留：只读数据库探测失败时关闭连接、保存计划前重新校验学科生命周期、禁用 AI 解析父开关时清除子功能、第三方材料校验和输出路径保护，以及发布回归证据检查。构建锁文件继续采用 Pillow 12.3.0、pip 26.2.1；这些与已发布安装包的原始锁文件有区别。

计划保存沿用 QML 版调用方管理的事务接口，仅在尚未开始事务时开启写事务，避免嵌套 `BEGIN` 破坏整份预算计划的保存和回滚。数据库、计划及兼容 QWidget 设置页共三个运行时文件含保留的维护修复；因此 `main` 是发行版源码与维护修复的整合结果，需要精确重现原包时仍应检出 `v1.0.0`。

## 本次验证范围

- 专项回归：244 项测试、2 项子测试通过，14 项因 Windows 链接创建权限限制跳过。
- 382 个 Python 源文件通过语法解析；受跟踪文件的工作副本与暂存 Git blob 一致，上传范围及凭据扫描通过。
- 完整回归原始结果：1700 项测试通过、5 项构建契约测试失败、17 项跳过，293 项子测试通过，4 条警告。失败原因是新副本缺少被 Git 忽略的 `output/` 目录，以及既有 QA 环境仍安装旧版 Pillow/pip。补建目录并准备匹配维护锁文件的独立 QA 环境后，构建专项 15 项全部通过，原 5 项失败均覆盖；应用源码和测试断言未为此修改。
- 按测试 ID 合并完整回归和补测，最终为 **1705 项测试、293 项子测试通过，17 项跳过，无未解决失败**。17 项跳过包含 3 项需要真实 Windows HWND/GUI 会话的测试和 14 项受链接创建权限限制的测试。此结果不是单次全量全绿；原始报告与补测报告分别保留。

本轮完整回归使用本地 CPython 3.14.5、Qt 6.11.1 的已有发行版测试环境，Pillow 为 12.1.0；没有将该环境表述为与维护锁文件完全一致。构建契约最终补测使用独立 CPython 3.12.14 QA 环境，锁定包清单匹配，Pillow 12.3.0、pip 26.2.1，`pip check` 通过。测试数据使用独立目录，未读取真实用户学习资料或调用外部 AI。

外部测试启动脚本曾因缺少 Windows 多进程入口保护而重复运行，已中止并修正；上述完整回归结果仅统计纠正后的运行，未引用该中止运行作为通过证据。

此同步不重新构建或替换已发布的安装包、标签及校验清单。已有发布验收文件保留原有历史含义；后续重新发行必须重新生成与候选源码、依赖及安装包对应的材料和验收证据。
