本阶段交付完整 QQuickWindow 中的学习助理与知识图谱业务增量。四条主路由接入真实服务，设置仍明确标记尚未迁移。本文件记录功能实现与隔离验证的范围；真实外部 AI/OCR 和 ChatGPT 桌面 PDF 端到端流程仍未签核。

## 已接入的业务

| 页面/用例 | 数据与业务来源 | 交互边界 |
| --- | --- | --- |
| 助理只读问答 | `core.dashboard`、`ai.natural_query` | 默认本地查询；仅本次明确勾选且原设置启用时请求外部补充。附件不由问答上传，外部失败保留本地答案。 |

| 撤销 | 原引擎及记录重放/修订仓储 | 先展示当前可撤销动作，再明确确认；确认前核对同一目标。缺少贡献痕迹时保留原业务拒绝行为。 |

| 预警处理/延后 | `knowledge_alerts`、事件仓储 | 显式确认目标及合法日期；事务内核对预警和学科版本，再调用原核心操作。显示活动、已处理、延后、解除状态与原审计事件。读取不隐式重算或创建预警。 |

## 架构与安全

- 新增 `assistant_service.py`、`knowledge_service.py` 和 `insights_bridge.py`。构造器只存显式路径和日期；服务方法在与首页、学习工作区共享的单线程任务队列执行。
- QML 只获得 JSON/Qt 兼容 DTO、固定槽和进程内预览句柄，不获得数据库连接、SQL、provider 密钥、引擎确认密钥或撤销能力对象。
- 引擎新增可选日期/记录路径注入，原 Widgets 默认调用保持兼容；自然语言问答的审计也使用注入数据库。重新预览恢复原审计中的请求和附件，再重新预检，不沿用旧确认。
- 提交成功与后续回读/刷新失败分开报告。异常恢复只在持久化证据可以归属到同一动作时提示已保存；不将目标状态已经存在直接当作本次提交的证明。
- 取消/超时只停止接收结果；忙碌状态直到实际线程结束才释放。退出在 GUI 事件循环外等待全部文件使用任务完成，再清理隔离目录。所有连接到 Qt 的轮询和数据失效处理均为静态 `@Slot`，保留阶段二 access violation 的根因修复。
- 页面快速切换时合并最新只读加载请求，不因上个页面仍忙碌而跳过新页面加载。后台写入结束后首页刷新，相关预览失效。

## 资源与启动自检

QML 资源白名单增加四个页面文件，总数 33；继续通过现有 PyInstaller spec 逐文件收集，不采用整目录扫描或背景图透明热区。源码和冻结自检加载完整窗口、五个路由、学习工作区四个页签、图谱/预警两个页签并检查实际可见状态及 QML 警告。

自检入口先创建临时用户数据目录，在后台向空隔离库导入两个章节、一条学习记录，再读取真实 SQLite 数据和本地问答。测试学科明确属于自检，不加入默认产品模型；已有用户数据不接受此种子写入。自检异常退出也先等待线程收尾。
