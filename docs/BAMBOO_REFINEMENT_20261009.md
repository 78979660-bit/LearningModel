# 侧栏细叶竹修缮

参照用户提供的四页概念图，仅调整左下角竹叶装饰。原图以大量重复扇形叶片分布在 280×500 的直立画布上，侧栏以 380 高度显示，空余区域不足时会截去顶部。

`tools/design_washi_assets.py` 的 bamboo() 现生成 280×340 SVG：两组斜生枝条、38 片分别沿枝附着的细长叶片，包含弯曲叶尖、灰绿深浅渐变、叶脉与少量淡叶。资源保持矢量格式，无外部图像请求或持续绘制动画。

`RouteSidebar.qml` 限制装饰宽度并按原比例确定高度，固定 SVG 栅格采样尺寸，布局缩放不重建图像资源。展开时最多约 248 高，完整枝梢进入空余区域；折叠时随已有侧栏宽度动画收拢并淡化，装饰不参与输入。空余高度不足 100 时隐藏，避免最小窗口出现极小的竹叶缩略图。

原生 Qt 6.11.1 隔离数据视觉检查：1280×850 展开侧栏 220 宽，竹叶 204×247.7；折叠后侧栏 72 宽，竹叶 56×68、透明度 0.38；1280×600 时隐藏装饰。三种窗口截图均已查看，资源加载成功，QML warning 为零。报告与截图位于 `output/bamboo-review-20261009-r5/`。诊断中需等待真实渲染帧及局部事件循环后再记录动画最终状态，未把早期截到的动画首帧当作完成结果。
