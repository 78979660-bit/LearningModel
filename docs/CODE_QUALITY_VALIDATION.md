# 源码质量整改验证

日期：2026-09-24。

本次修改覆盖源码审查中发现的配置副作用、OCR 运行时判断不一致、AI 子功能开关失效、审计失败被吞掉、数据层职责混杂，以及学习计划页过大的问题。

主要变更：

- 复制 LLM 配置后再调整请求参数，避免污染共享配置；统一 OCR 运行时检测。
- 将 AI 子功能开关应用于提示词和结果过滤，保留审计失败与降级原因。
- 拆分数据库运行时、领域仓储和设置审计存储；用公开事务接口管理读取与连接生命周期。
- 将学习计划页拆为预算面板、详细计划面板和独立复习模式弹窗，保留原有页面回调与后台任务约定。
- 清理重复逻辑和遗留入口，增加配置、事务、页面状态隔离及弹窗行为测试。
