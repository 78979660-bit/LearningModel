# 和纸材质增强

参照用户提供的四页概念图，增强细颗粒、短纤维、轻微纸浆明暗和薄纸边缘层次。覆盖背景、侧栏、共享 PaperCard 与聊天气泡，正文颜色和 150% 行距保持原有设置。

## 实现

- `tools/design_washi_assets.py` 的 paper 工厂保留固定随机种子、960×960 尺寸与矢量纤维边界包裹。长纤维缩短，增加暖灰纤维的可见度，保留 3,200 条纤维与 3,000 个微孔颗粒。
- 细密噪声用标准库生成透明 PNG 后嵌入原 SVG；没有外部图片地址或新增独立资源路径。所有表面依然加载同一个 paper-texture.svg、同一 sourceSize，并使用 QML Image 静态缓存。没有增加 Canvas 重绘、动态噪声、模糊滤镜或额外离屏图层。
- PaperCard 表面更实，边缘轻微起伏、细边线、上边高光与下边暖灰细线形成纸张厚度，调整两层贴近表面的静态阴影与低强度纸面渐变。
- 主背景与侧栏分别以 0.80 / 0.74 显示纹理；卡片 0.90，助理气泡 0.48、用户气泡 0.25。聊天纹理位于文字后，选择复制和字面文本转义仍有效。
