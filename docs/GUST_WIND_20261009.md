# 阵风与动态花瓣修订 · 2026-10-09

根据用户反馈，将持续、等频的往复摆动改为同方向阵风。三阵风的力度、吹入时间和回落时间不同，中间有较长安静段。樱花先响应，竹子稍晚响应，风中带小幅枝叶颤动；纸角随同一阵风翘起。沿用一个共享时钟，64 秒循环，后台、隐藏、最小化、启动准备和用户关闭效果时暂停。

宽窗口动态花瓣从 7 片增加至 34 片：24 片位于纸面下，10 片较淡的花瓣经过顶部。窄窗口 15 片。花瓣朝同一方向横向掠过，速度根据风压积分平滑加速、回落，避免直接乘风力导致位置跳动。花瓣大小、翻转和轨迹错开。
