# 动态背景与风感 · 2026-10-09

后续已按用户反馈改为阵风并增加动态花瓣、清除静止花瓣。当前行为与验证见 `GUST_WIND_20261009.md`；以下保留首版记录。

右上樱花、左下细叶竹随同一阵轻风缓慢摆动，少量花瓣沿弧线下降。宽窗口最多 7 片花瓣，小窗口 3 片；花瓣位于内容下面，正文和控件不会被覆盖。较大的纸卡片约每 28 秒出现一次约 5 秒的角落翘起，翘角限于至少 22 像素的内边距，正文和输入布局不随之移动。

左下角“···”菜单新增“动态背景”开关，默认开启，当前打开期间可关闭。开关暂不跨重启保存。窗口不活跃、隐藏、最小化或启动准备期间，共享时钟暂停；恢复窗口后继续原来的进度。关闭效果时樱花、竹子恢复静态，花瓣与动态翘角隐藏。

## 实现

- `Theme.qml` 提供一个共享相位，`Main.qml` 的 28 秒动画驱动，暂停逻辑直接跟随窗口和预加载状态。
- 樱花和竹子只做绕枝干方向的旋转，不改变锚点、尺寸或布局。
- 花瓣和翘角使用静态 Shape 几何与渐变，动画只改变位置、旋转、缩放和透明度。没有每帧 Canvas 绘制、纹理生成、模糊或业务数据读取。
- 修改现有四个已列入资源清单的 QML 文件，无新增运行依赖。
