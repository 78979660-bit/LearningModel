## 1.0.0 版本与文档调整的核验范围

1.0.0 仅调整版本元数据与说明文档。逐文件比较 240 个运行时输入，只有 `app_metadata.py` 的版本字符串和版本四元组变化；其余功能源码、QML、资源与已发布的 0.1.2 完全一致，200 个原生 DLL/PYD 的哈希也完全一致。安装器仅改变版本标签，AppId、数据目录及 schema v5 未变。

本次重新构建并核验版本资源、冻结自检、68 项相关测试，补测 Windows 10 升级/卸载保留资料/重装以及 Windows 11 升级与资料保留；未改变功能的全部回归、DPI、真实 OCR、业务流程和稳定性保留原始证据并注明沿用。具体范围见 [1.0.0 验收说明](RELEASE_ACCEPTANCE_1.0.0.md)。不把历史测试算作本版重跑，也不通过只改文件名来更换安装包版本。

此范围仅适用于本次经过逐文件确认的版本标签调整。出现功能、界面、依赖、数据结构或安装行为变更时，应重新按下面完整清单确定验收范围。

适用版本：0.1.0 及后续版本。每次候选构建复制本表，填写版本、构建者、日期、机器/虚拟机快照与证据路径。未勾选项不得按“已验证”对外说明。

> **新候选包的发布门槛：** 项目已选择 AGPL-3.0-only；每次新二进制仍须提供匹配的项目源码、第三方对应源码及许可材料，并完成本次功能与安装验收。旧版本的验收不能代替 QML 迁移候选包验收。收集许可证文本不等于关闭全部分发义务。
