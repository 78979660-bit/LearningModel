# Windows 扫描 PDF OCR 修复

2026-10-11：已修复扫描 PDF OCR 的语言包路径参数错误，真实中文路径及中文含空格路径验证通过。此修复形成新的 0.1.2 测试候选包，尚未签名或上传。

`subject_pdf_pipeline._default_ocr` 改为以独立参数直接调用 Tesseract，PNG 通过标准输入传入，TSV 结果保留原有文本、置信度及页面坐标含义。调用不再设置 `pytesseract` 的全局执行文件路径，也不再将语言包目录拼入配置字符串。每页执行上限为 30 秒，Windows 子进程隐藏控制台窗口；引擎错误输出先按 UTF-8 解码，再使用本地编码处理，避免错误被 `UnicodeDecodeError` 掩盖。
