# 开源发布范围与决定

2026-09-23，项目负责人选择开源分发路线。本仓库项目自身代码使用 AGPL-3.0-only；不采用 PyMuPDF 商业许可路线。

## 本次公开内容

应用源码、算法模块、干净默认资源、测试、安装包构建配置、必要工具、第三方许可收集结果和构建说明。没有上传原项目 Git 历史。

排除个人数据库、根目录学习模型和记录 JSON、API 凭据、备份、迁移回执、性能日志、私有教材和作业。排除一次性的个人记录修订工具，以及含个人资料路径、未进入安装包的化学资料导入脚本。两个旧测试改为使用人工构造的测试学科和记录。

## 已选定许可，不等于已完成二进制发布

选择 AGPL 后，需要为实际发布版本提供对应源码及构建材料，并保留第三方许可和归属声明。项目源码的公开不自动补齐所打包第三方二进制的全部分发材料。

当前安装包继续保留 Release 草稿。公开二进制前还需：

- 收集并固定实际捆绑的 PyMuPDF/MuPDF、Qt/PySide/Shiboken 等组件对应版本的源码及其必要构建材料，核对传递依赖和源码下载路径。
- 复核 Qt 及其他第三方组件的许可文本、归属声明与分发方式。原自动收集结果含仅有商业许可提示的项目，不能直接视为完整。
- 将项目许可、第三方材料和对应源码链接随实际发布物提供；更新旧发布说明中的“未选择许可”状态。
- 从已发布提交构建并记录产物来源；完成干净 Windows 环境验收。签名另行安排，目前候选包未签名。

这份文件记录项目的许可选择和实施状态，不宣称所有第三方分发义务已经完成。
