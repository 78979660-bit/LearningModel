# 开源发布范围与决定

2026-09-23，项目负责人选择开源分发路线。本仓库项目自身代码使用 AGPL-3.0-only；不采用 PyMuPDF 商业许可路线。

## 本次公开内容

应用源码、算法模块、干净默认资源、测试、安装包构建配置、必要工具、第三方许可收集结果和构建说明。没有上传原项目 Git 历史。

排除个人数据库、根目录学习模型和记录 JSON、API 凭据、备份、迁移回执、性能日志、私有教材和作业。排除一次性的个人记录修订工具，以及含个人资料路径、未进入安装包的化学资料导入脚本。两个旧测试改为使用人工构造的测试学科和记录。

## 已选定许可，不等于已完成二进制发布

选择 AGPL 后，需要为实际发布版本提供对应源码及构建材料，并保留第三方许可和归属声明。项目源码的公开不自动补齐所打包第三方二进制的全部分发材料。

## 2026-09-23 材料补充结果

已收集 35 个确切版本的第三方源码归档、提取 371 份许可/归属文本，并记录 79 个原生 DLL/PYD 的哈希与组件映射。见 [材料说明](RELEASE_SUPPLEMENT.md)、`third-party-source-manifest.json`、`third-party-notice-manifest.json` 和 `native-binary-inventory.json`。

Qt/PySide 的开源许可全文已从相应版本源码补齐，不能再只依据 wheel 内的商业许可提示判断。MuPDF 内核、Mesa/LLVM 和 CPython 原生依赖源码已单独收集。

当前安装包继续保留 Release 草稿。本次重建包含卸载数据选项和中文时间校验；源码、安装包、验收脚本及附件哈希一起更新。第三方依赖锁定版本未变。

Windows 11 虚拟机已完成安装、主要界面、学科管理、计划和卸载重装检查。覆盖范围及未测项目见 [验收说明](RELEASE_ACCEPTANCE.md)。没有将部分验收宣称为完整兼容性认证。

正式发布时应将第三方实际源码归档、项目源码和许可材料与安装包一起提供，保留版本关系和下载可用性。安装包未进行代码签名。本文件记录实施状态，不宣称所有第三方分发义务已经完成。
