# 学习助理对话修缮

用户反馈学习助理像工作报告、直接铺开依据和来源，输入问题只能点按钮发送。本轮修缮针对正常 --qml 入口。

## 最终行为

- 问答使用左右聊天气泡：用户在右，助理在左。保留本次打开应用期间的问答，切换页面与刷新不清空；文本可选择复制，等待和失败结果也留在对应气泡中，失败可重新发送。内存记录最多保留 40 轮，不新增数据库表或跨启动对话存储；历史用于界面呈现，问答请求仍只发送本次问题。
- 输入框固定在聊天区下方。Enter 与小键盘 Enter 发送，Shift+Enter 换行；空白输入、等待中的重复发送和按键自动重复不产生额外请求。中文预编辑期间的回车不发送或插入换行。发送后清空已发文本，等待期间仍可写下一条草稿。
- 回答直接展开自然中文，去掉查询结果、回答、依据、来源的固定报告标题。参考记录默认折叠到“为什么这样建议”，每轮回答各自保留其依据；外部顾问失败的本地回退仍明确提示。
- 本地问答识别“加强、补强、重点、不足”等常见问法，按明确学科筛选记忆与答题风险。首页有限待办队列没有包含该学科时，仍从该学科的实际加权候选或风险项给建议，不误报为没有复习内容。风险估计数字留在参考记录，不把模型估计写成确定的个人表现；没有近期得分时不声称达标。
- 外部问答保留只读与不可信数据边界，在既有 JSON 格式内要求自然短段落、指定学科聚焦、避免内部字段名和工作报告语气。学习安排、记录修改仍通过原来的预览、复核、确认流程，普通发送不创建操作提案。材料仍仅由预览解析，不因聊天发送而读取或外发。按用户后续要求，问答默认优先使用外部模型，手动取消后在本次启动内切页保留本地选择，详见下文。
