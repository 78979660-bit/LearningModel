# 学习模型 0.1.0 第三方许可说明

本文件是发布审查清单，不是法律意见。最终发布材料必须同时提供构建环境中各发行包携带的原始 LICENSE、COPYING、NOTICE 等文件。运行：

```powershell
& .\.venv-build\Scripts\python.exe .\tools\collect_licenses.py `
  --lock-file .\requirements-build.lock.txt `
  --output .\release\artifacts\THIRD_PARTY_LICENSES `
  --include-build-tools
```

脚本会核对已安装版本与锁定文件，复制发行包自带的许可文本，并生成 `LICENSE-MANIFEST.json`。自动收集不能替代对源代码提供、动态链接、归属声明、修改说明和商业许可范围的人工判断。

## 发布材料要求

- 发布包只使用 `requirements-build.lock.txt` 指定的版本，并保存构建记录。
- 把 `THIRD_PARTY_LICENSES` 与本说明一并提供给接收者；若许可要求在应用内可访问，还需加入应用“关于/许可”入口。
- 不要从开发机复制未知 DLL、字体、OCR 模型、教材、题库或图像到 `dist`。
- 若加入 Tesseract、语言数据、字体、OpenSSL 或其他可选二进制，先更新锁定清单、白名单、许可证收集逻辑和本说明。
- 每次升级依赖版本后重新收集并人工审查许可，不得沿用旧结论。
