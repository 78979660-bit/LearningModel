# 学习模型 0.1.0 安装与升级说明

## 支持范围

- Windows 10 1809 或更高版本，x64 处理器。
- 安装和日常使用不需要另行安装 Python、Qt、Git 或开发工具。
- 当前候选包仅用于内部/QA 验收。由于 PyMuPDF 许可方案尚未确认，0.1.0 暂不具备公开分发条件。

## 安装

1. 从受信任的内部渠道取得 `LearningModel-Setup-0.1.0-x64.exe` 和 `SHA256SUMS.txt`。
2. 在 PowerShell 中校验文件：

   ```powershell
   Get-FileHash -LiteralPath '.\LearningModel-Setup-0.1.0-x64.exe' -Algorithm SHA256
   ```

   结果应与 `SHA256SUMS.txt` 完全一致。若不一致，不要运行安装器。
3. 双击安装器。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\LearningModel`，无需管理员权限。
4. 可选择创建桌面快捷方式；开始菜单会创建“学习模型”入口。
5. 首次启动会在用户目录创建干净数据，不会导入发布者机器上的数据库或学习记录。

## 数据位置与备份

用户数据与程序安装目录分离，默认位于 `%LOCALAPPDATA%\LearningModel`：

```text
data\       学习数据库和个人配置
backups\    升级及学科操作备份
logs\       启动、运行和性能诊断日志
cache\      可重新生成的缓存
exports\    应用生成的默认导出位置
```

安装、覆盖升级、卸载和重新安装默认都保留此目录。升级或卸载前仍建议复制整个 `%LOCALAPPDATA%\LearningModel` 到安全位置。不要在应用运行或数据库写入时直接替换数据文件。

## 升级

1. 退出学习模型；如安装程序提示程序仍在运行，请在应用内正常退出后继续。
2. 备份 `%LOCALAPPDATA%\LearningModel`。
3. 运行新版本安装器。固定 AppId 会让安装程序识别已有安装并覆盖程序文件。
4. 首次启动新版本时等待数据库检查/迁移完成，不要强制结束进程。
5. 检查学科、记录、当前计划和设置。若启动失败，请保留原数据和 `%LOCALAPPDATA%\LearningModel\logs` 后再反馈。

不要用旧版本打开已经由不兼容新版本升级的数据。遇到降级提示时停止写入并从备份恢复，或重新安装兼容版本。

## 卸载与重装

从 Windows“已安装的应用”卸载“学习模型”。卸载器只移除程序文件和快捷方式，不删除 `%LOCALAPPDATA%\LearningModel`。因此重装后可继续使用原数据。

如确实要清除所有个人数据，请先导出或备份，确认应用已退出，再由用户本人单独删除 `%LOCALAPPDATA%\LearningModel`。此操作不可由默认卸载流程代替。

## 可选能力

- OCR 需要单独安装 Tesseract，或按应用支持的方式放置本地引擎；缺失时 PDF OCR 不可用，但核心学习流程应可用。
- ChatGPT 桌面桥接需要已安装、已登录且处于可用状态的 ChatGPT Windows 应用；缺失时应用会停用对应能力。
- AI 服务密钥由用户自行配置，安装包不包含任何预设密钥。
- 应用启动时不主动联网探测网络服务；离线时核心本地功能仍应可用。

应用不会把个人数据库放进安装目录。诊断日志保存在本机用户目录；发布版的遥测/上传策略必须以实际发布说明为准。
