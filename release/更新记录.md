# 学习模型更新记录

## 0.1.0（内部候选版，尚未公开发布）

发布日期：待定。

### 新增

- Windows 10+ x64 桌面应用的 PyInstaller `onedir` 构建配置。
- 当前用户范围的 Inno Setup 安装、开始菜单入口和可选桌面快捷方式。
- 统一应用身份、版本资源与固定升级 AppId。
- 独立用户数据目录、干净默认数据和已有开发版数据的备份式迁移入口。
- 数据库初始化/版本迁移、自检和可选外部能力检测。
- 严格发布资源白名单、隐私数据排除检查和安装包验证脚本。
- 第三方许可文本收集、SHA-256 生成及发布验收检查表。

### 数据与升级

- 用户数据默认保存在 `%LOCALAPPDATA%\LearningModel`，与 `%LOCALAPPDATA%\Programs\LearningModel` 程序目录分离。
- 覆盖安装和默认卸载不会删除学习记录、学科、设置、备份或日志。
- 首次启动使用清理后的通用默认模型与空记录集；安装包不包含开发者个人数据。

### 已知限制与阻断

- **公开发布阻断：** PyMuPDF 1.27.2.3 的 AGPL 合规方案或适用商业许可尚未确认。解决并记录审查结论前，本版本只能用于内部/QA 验收，不得公开分发。
- 安装器与应用的正式代码签名需要在获得发布证书后完成；未签名内部包可能触发 Windows SmartScreen。
- OCR 依赖外部 Tesseract 引擎；未安装时 OCR 不可用。
- ChatGPT 桌面桥接依赖外部桌面应用；缺失时不影响本地核心功能。
- 自动更新尚未实现；升级使用新版安装器覆盖安装。
