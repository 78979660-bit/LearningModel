# 学习模型更新记录

## 1.0.0（未签名正式版，2026-10-13）

- 将应用显示、Windows 文件资源、安装器和构建默认版本统一为 1.0.0，重新构建程序与安装包。
- 按原 README 开场的亲切、轻松语气改写功能介绍、安装说明和开发入口，保留使用条件与已测范围。
- 功能实现沿用已发布的 0.1.2，用户数据目录、AppId 和 schema v5 保持兼容。

本版的版本专项测试、冻结自检和安装生命周期补测，以及与 0.1.2 历史验收的关系，见 [1.0.0 验收说明](../docs/RELEASE_ACCEPTANCE_1.0.0.md)。历史测试结果不冒充本版重新执行的结果。

## 0.1.2（未签名正式版，2026-10-13）

- 常规入口使用 QML，优化学科列表刷新、页面切换、菜单动画及资源加载。
- 修复单学科计划混入其他学科任务。
- 修复留空分数显示 undefined；空分数与 0 分正确区分。
- 修复 Windows OCR 语言包路径参数，支持中文和含空格路径；纯扫描 PDF 无文本页回退至图片 OCR。
- 保留用户数据目录、升级 AppId 和 schema v5。本地练习卷及 PDF 导出保留，移除 ChatGPT 桌面 PDF 桥接。

11 项发布前验收通过，包括 Windows 10/11 安装生命周期、非空数据保留、实际系统多档 DPI、真实冻结程序 OCR 和 90 分钟稳定性。详见 [正式版验收](../docs/UNSIGNED_RELEASE_ACCEPTANCE_0.1.2.md)。程序和安装器未签名，外部 AI 的所有服务商与网络环境未穷举。

## 0.1.1（公开预发布测试版，2026-10-03）

- 拆分学习计划页、复习弹窗及数据库领域仓储，明确事务和连接生命周期。
- AI 子功能开关同时控制提示词和结果处理；复制请求配置，保留审计失败与降级原因。
- 统一 OCR 运行时检测，清理遗留实现及重复判断。
- 学习覆盖识别已掌握、已学待复习状态；仅指向章节的记录不会覆盖全部知识点。
- 学科目录尚未采用结构时保留已有模型章节；已采用的空结构继续作为权威数据。
- 综合计划使用实际优先知识点计算难度，并识别已有证据但仍显示无证据的旧计划。
- 应用、Windows 版本资源与构建默认版本统一为 0.1.1；修正测试临时目录权限冲突。

完整回归：1127 项测试、279 项子测试通过，5 条既有弃用警告。冻结程序自检和安装包结构/版本检查通过。正常登录虚拟机后，升级、卸载保留数据、重装及独立空配置检查通过；五个主要页面、菜单展开/收起及窗口最大化/还原实测通过。本地打包与安装生命周期通过，完整发布签核仍有未测项，非空学习记录保留未实测；详见 docs/RELEASE_ACCEPTANCE_0.1.1.md。

用户数据目录、升级 AppId 和数据库 schema v5 保持兼容。安装包未签名。真实外部 AI/OCR、Windows 10 和多档系统 DPI 未在本轮完成端到端验收。
